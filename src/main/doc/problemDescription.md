# Проблема двойной записи (dual write)

`POST /orders` сохраняет заказ в PostgreSQL и отправляет событие в Kafka двумя
независимыми операциями. Общей транзакции у них нет.

## Сценарий: падение приложения между save и send
1. Запустить приложение с breakpoint на `kafkaTemplate.send(...)`.
2. Отправить `POST /orders`.
3. Когда приложение остановилось: `jps -l`, затем `kill -9 <PID>`.
4. Запустить приложение заново.

## Результат
- `SELECT * FROM order_entity;` -> заказ есть
- consumer на топике `order-created-events-topic` -> события для этого заказа нет

## Вывод
Заказ создан, а событие потеряно, и ничто его не повторит.
Это проблема, которую решает Transactional Outbox (Спринт 1).
